## 2. N／AN 及 hard／soft 分工

N：當日21:15至翌日07:15。

AN（A/N）：同一日 A07:00–14:30，加同日夜間21:30至翌日07:15。這是一個複合更次、兩段工作；14:30–21:30不是連續當值。N 單更與 AN 夜段起點不同，不會強行改成同一時間。

適用職系 HW、RCW、CW。每日最少3名**不同 RCW**返 N 或 AN／A-N，是硬性運作需求；不是任意三名 HW／RCW／CW，也不是各更各三名。同一人不能因兩個代號重複計數，仍須逐時段核對實際覆蓋。

適用／有資格同事每月2–3次 AN是**軟性公平目標**，不是強制正好次數。AN只計一次，以起始更表日期落入相應 calendar month；N次數另列，不偷偷當成合併 N+AN 配額。未達公平目標會報偏差，不會單靠這個阻止發布。「6日已排好」已從有效需求刪除。

鐘面時段不等於已確認應付／計帳工時；不自行扣膳、加費率或把 split gap 計入工時。如果翌日另派07:00開始嘅A，與上一晚07:15落更有重疊，系統必須指出，不能因新更日期不同就當沒有冲突。AN21:30才開始，不能假稱21:15–21:30已在場。

## 3. 任務 +1 與 base 抽調

「+1 RN／HW／CW」預設是在 East／West基本人手之外額外加人，按真正任務時段計資格、覆蓋及預算。

額外人手沒有時，系統可以提出 base 抽調方案，併入原有完整更表／申請審批，由有權者一併接受，不新增每一項工作都要反覆問人嘅流程。抽走後必須重驗原單位剩餘人手、法定／已確認硬要求、任務資格及費用；同一人不能同時當作兩邊兼容以外嘅全數人手，更不能重複收費。

如果抽調後出現硬性不足，先顯示阻礙及合法可行替代方案；不能自動把法律或已批准承諾切成「盡量滿足」。只有已明確確認嘅兼做／同場同時規則才可使用相應計數，未知不雙計。
