# NAAC Shift Code Dictionary & Hours

## Basic Shift Codes

| Code | Duration | Notes |
|------|----------|-------|
| A | 8 hours | Day shift. The number after 'A' = start time (e.g. A7 = starts 07:00, ends 15:00) |
| B | 9 hours | Extended day shift (e.g. B7 = 07:00–16:00) |
| C | 3 hours | Sleepover shift (work: 22:00–22:30 + next day 06:30–07:00) |
| F | 6 hours | Short shift |
| G | 7 hours | Reduced day shift (e.g. G7 = 07:00–14:00) |
| K | 10 hours | Long night shift (e.g. K10 = 22:00–08:00 next day) |
| S | 4 hours | Short shift |
| Ss | 4.5 hours | Short shift (extended) |
| P | Until 10pm | Afternoon/evening shift (ends 22:00) |
| N | 9 hours overnight | Night shift. N10 = 22:00–07:00(next day); N1015 = 22:15–07:15(next day) |
| O | Day off | Red O = statutory rest day; Black O = non-statutory day off |
| NO | Post-overnight rest | Rest day after overnight shift |

## Modifiers (appended to shift code)

| Modifier | Meaning |
|----------|---------|
| s | +30 minutes |
| x | +10 minutes |
| v | +5 minutes |
| # | Duty supervisor on that shift |

**Rule:** The number after the letter = start time. End time = start time + code duration.

## Combined/Special Shift Codes

| Code | Breakdown | Total Hours |
|------|-----------|-------------|
| A7N10 | A7 (07:00–15:00) + N (22:00–07:00 next day) | 17h |
| A7N1015 | A7 (07:00–15:00) + N (22:15–07:15 next day) | 17h |
| A7s | A7 (07:00–15:00) + s (15:00–15:30) | 8.5h |
| G7sN10 | G7 (07:00–14:00) + s (14:00–14:30) + N (22:00–07:00 next day) | 16.5h |
| N1030 | 22:30–07:00 next day (long N or substitute N) | 8.5h |
